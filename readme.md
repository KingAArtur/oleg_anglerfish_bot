Это - небольшой телеграм-бот, созданный для развлечения нашей небольшой группы друзей!

Основные функции:
- болтать -- отвечает на сообщение пользователя, используя n-gramную модель
для генерации текста, в результате выдавая правдоподобный, но весьма бессмысленный
текст. Еще иногда может материться ^^
- делать гороскопы -- генерирует "гороскоп", зависящий от имени пользователя
и текущего дня.
- всякие мелочи, например, случайно выбрать одну из нескольких опций,
или назвать того, кого он сегодня любит.

Написано на Python 3.11 при помощи библиотеки python-telegram-bot.
Для работы с языком -- pymorphy3 и nltk.
Постарался разделить логику самого бота от логики работы с телегой,
поэтому бота можно и просто в консоли запускать.
